# EXE SNOWGLOBE · asset host

Hosted files for the **EXE SNOWGLOBE** StreamElements widget by form&soul.exe
(GitHub Pages: https://feder0707.github.io/exe-snowglobe-assets/).

- `engine/snowglobe.js` — scene engine loaded by the widget (v1.1)
- `assets/` — scene images (WebP) and `scene.json`
- `sounds/` — the widget sounds (MP3, CC0)
- `fonts/` — Elsie, Elsie Swash Caps, Quicksand, Playfair Display and Cinzel (latin) with their SIL OFL licences
- `index.html` — preview of the scene (no events, no sound, nothing is saved)
- `CREDITS.md` — sounds, fonts and art

Do not rename this repository or move files: purchased widgets load them from these URLs.
